# Secret Chat 新功能说明

## 🆕 新增功能

### 1. 主页发帖系统
- **发帖界面**：类似论坛的主页，可以浏览所有帖子
- **发新帖**：点击"发新帖"按钮可以创建新帖子
- **帖子内容**：支持文本内容和图片
- **频道信息**：每个帖子显示频道名和发帖时间
- **加入频道**：点击"加入频道"按钮可以直接进入对应频道聊天

### 2. 图片发送功能
- **聊天图片**：在聊天界面可以发送图片
- **发帖图片**：发帖时可以添加图片
- **图片预览**：发送前可以预览图片
- **图片查看**：点击图片可以全屏查看
- **图片格式**：支持常见图片格式（JPG、PNG、GIF等）

### 3. 界面优化
- **双页面设计**：主页和聊天页面分离
- **导航按钮**：可以方便地在主页和聊天间切换
- **响应式布局**：适配不同屏幕尺寸
- **深色主题**：保持原有的深色主题风格

## 🎯 使用流程

### 发帖流程
1. 打开插件，默认显示主页
2. 点击"发新帖"按钮
3. 填写频道名、昵称和帖子内容
4. 可选择添加图片
5. 点击"发布"完成发帖

### 加入频道流程
1. 在主页浏览帖子
2. 找到感兴趣的帖子
3. 点击"加入频道"按钮
4. 输入昵称
5. 自动进入聊天界面

### 发送图片流程
1. 在聊天界面点击📷按钮
2. 选择图片文件
3. 图片自动发送到当前频道

## 🔧 技术实现

### 前端技术
- **HTML5**：使用File API处理图片上传
- **CSS3**：响应式布局和动画效果
- **JavaScript**：图片预览、页面切换、数据管理

### 数据存储
- **LocalStorage**：帖子数据本地存储
- **Base64编码**：图片数据编码存储
- **JSON格式**：结构化数据存储

### 消息协议
```javascript
// 发送图片消息
{
  cmd: "chat",
  text: "[图片]",
  image: "data:image/jpeg;base64,..."
}

// 帖子数据结构
{
  channel: "频道名",
  nick: "发帖人昵称", 
  content: "帖子内容",
  timestamp: 1234567890,
  image: "data:image/jpeg;base64,..." // 可选
}
```

## 📱 界面说明

### 主页界面
- **页面头部**：显示标题和发新帖按钮
- **帖子列表**：显示所有帖子，按时间倒序
- **帖子卡片**：包含频道名、时间、内容、图片和加入按钮

### 聊天界面
- **消息区域**：显示聊天消息和图片
- **输入区域**：文本输入框、图片按钮、发送按钮、切换按钮、返回按钮
- **图片显示**：消息中的图片可以点击查看大图

### 发帖模态框
- **基本信息**：频道名、昵称输入框
- **内容编辑**：多行文本输入框
- **图片上传**：文件选择和预览区域
- **操作按钮**：取消和发布按钮

## 🚀 部署说明

### 客户端部署
1. 将 `client/` 文件夹复制到 Adobe CEP 扩展目录
2. 重启 Adobe 软件
3. 在菜单中找到 "Secret Chat" 面板

### 服务器部署
1. 进入 `server/` 目录
2. 运行 `npm install` 安装依赖
3. 运行 `npm start` 启动服务器
4. 或使用 `./deploy.sh` 进行云服务器部署
