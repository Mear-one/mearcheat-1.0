# Secret Chat 功能说明

## 🆕 最新功能

### 1. 加密频道系统 ⭐
- **密码保护**：创建频道时可以设置密码
- **安全验证**：加入加密频道需要输入正确密码
- **服务器验证**：密码验证在服务器端进行，确保安全性
- **错误提示**：密码错误时提供清晰的错误信息
- **频道标识**：加密频道显示🔒图标

### 2. 频道管理系统
- **频道创建**：可以创建带密码的私有频道
- **频道删除**：频道创建者可以删除自己的频道
- **频道列表**：显示所有活跃频道和在线人数
- **自动清理**：无人频道自动删除
- **频道描述**：每个频道都有详细的描述信息

### 3. 主页发帖系统
- **发帖界面**：类似论坛的主页，可以浏览所有帖子
- **发新帖**：点击"发新帖"按钮可以创建新帖子
- **帖子内容**：支持文本内容和图片
- **频道信息**：每个帖子显示频道名和发帖时间
- **加入频道**：点击"加入频道"按钮可以直接进入对应频道聊天

### 4. 图片发送功能
- **聊天图片**：在聊天界面可以发送图片
- **发帖图片**：发帖时可以添加图片
- **图片预览**：发送前可以预览图片
- **图片查看**：点击图片可以全屏查看
- **图片格式**：支持常见图片格式（JPG、PNG、GIF等）
- **PS拖拽**：图片可以直接拖拽到Photoshop中

### 5. 界面优化
- **双页面设计**：主页和聊天页面分离
- **导航按钮**：可以方便地在主页和聊天间切换
- **响应式布局**：适配不同屏幕尺寸
- **深色主题**：保持原有的深色主题风格
- **全局昵称**：统一的昵称设置系统

## 🎯 使用流程

### 创建加密频道流程
1. 打开插件，默认显示主页
2. 点击"创建频道"按钮
3. 填写频道名、描述和密码
4. 可选择添加图片
5. 点击"创建"完成频道创建
6. 自动进入新创建的频道

### 加入加密频道流程
1. 在主页浏览频道列表
2. 找到带🔒图标的加密频道
3. 点击"加入"按钮
4. 输入频道密码
5. 验证通过后自动进入聊天界面

### 发帖流程
1. 打开插件，默认显示主页
2. 点击"发新帖"按钮
3. 填写频道名、昵称和帖子内容
4. 可选择添加图片
5. 点击"发布"完成发帖

### 加入频道流程
1. 在主页浏览帖子
2. 找到感兴趣的帖子
3. 点击"加入频道"按钮
4. 如果是加密频道，输入密码
5. 自动进入聊天界面

### 发送图片流程
1. 在聊天界面点击📷按钮
2. 选择图片文件
3. 图片自动发送到当前频道
4. 可以点击图片查看大图
5. 可以拖拽图片到Photoshop

## 🔧 技术实现

### 前端技术
- **HTML5**：使用File API处理图片上传
- **CSS3**：响应式布局和动画效果
- **JavaScript**：图片预览、页面切换、数据管理

### 数据存储
- **LocalStorage**：帖子数据本地存储
- **Base64编码**：图片数据编码存储
- **JSON格式**：结构化数据存储

### 消息协议
```javascript
// 加入加密频道
{
  cmd: "join",
  channel: "频道名",
  nick: "昵称",
  password: "密码"
}

// 发送图片消息
{
  cmd: "chat",
  text: "[图片]",
  image: "data:image/jpeg;base64,..."
}

// 帖子数据结构
{
  channel: "频道名",
  nick: "发帖人昵称", 
  content: "帖子内容",
  timestamp: 1234567890,
  image: "data:image/jpeg;base64,...", // 可选
  password: "频道密码", // 可选，用于加密频道
  isChannelCreation: true // 标识是否为频道创建帖子
}

// 频道数据结构
{
  name: "频道名",
  userCount: 5, // 在线人数
  owner: "创建者昵称",
  hasPassword: true, // 是否有密码
  password: "频道密码" // 密码信息
}
```

## 📱 界面说明

### 主页界面
- **页面头部**：显示标题和发新帖按钮
- **帖子列表**：显示所有帖子，按时间倒序
- **帖子卡片**：包含频道名、时间、内容、图片和加入按钮

### 聊天界面
- **消息区域**：显示聊天消息和图片
- **输入区域**：文本输入框、图片按钮、发送按钮、切换按钮、返回按钮
- **图片显示**：消息中的图片可以点击查看大图

### 发帖模态框
- **基本信息**：频道名、昵称输入框
- **内容编辑**：多行文本输入框
- **图片上传**：文件选择和预览区域
- **操作按钮**：取消和发布按钮

## 🚀 部署说明

### 客户端部署
1. 将 `client/` 文件夹复制到 Adobe CEP 扩展目录
2. 重启 Adobe 软件
3. 在菜单中找到 "Secret Chat" 面板

### 服务器部署
1. 进入 `server/` 目录
2. 运行 `npm install` 安装依赖
3. 运行 `npm start` 启动服务器
4. 或使用 `./deploy.sh` 进行云服务器部署

## 🐛 已知问题

1. **图片大小限制**：大图片可能导致性能问题
2. **存储限制**：LocalStorage 有大小限制
3. **网络依赖**：需要稳定的网络连接
4. **浏览器兼容**：某些旧版本浏览器可能不支持
5. **密码安全**：密码以明文传输，建议使用HTTPS
6. **频道清理**：无人频道会自动删除，可能丢失历史消息
